# AI现场诊断工具

本目录保留仍能服务当前D435工位的工具；阶段1采集、标注及评测统一使用assembly_vision/tools下的part_dataset系列。
主进度见[现状与交接](../docs/现状与交接.md)，统一命令见[架构与命令](../docs/架构与命令.md)，工位实测数字见[工位实测记录](工位帧/工位实测记录.md)。

## 保留工具

| 文件 | 用途 |
|---|---|
| live_site_debug.py | 实时画面、分割叠加和现场调参；写配置前确认真实工位条件 |
| capture_site_frame.py | 抓工位原图及诊断叠加 |
| d435_intrinsics_check.py | 分辨率内参与当前相机控件对账 |
| seg_gamut_report.py | 已有图像的色域和金属掩膜诊断 |
| d435_stream_diag.py | 开流能力与profile诊断 |
| d435_busy_probe.py | 设备被占用诊断，复位操作会影响相机状态 |
| d435_fps_ceiling.py | 纯读帧速率测量，避免显示/写图影响计时 |
| sweep_camera_controls.py | 在工位明确需要时扫描曝光/白平衡，不作为离线调参替代 |

在仓库根目录用D:\miniconda\envs\yolov11\python.exe运行。相机工具需SDK、USB3及普通桌面终端；用户不在工位时只运行已有原图离线评测。

## 数据与归属

- 阶段1数据/：本机真实原图、人工标注、模板和实验结果，被Git忽略。不能因清理工具而删原图或人工掩膜。
- 工位帧/：保留的工位原图和实测依据，旧截图中的结论按当时条件解释，不代表当前独立验收。
- 用户存档/predict.py是用户自己的测试脚本，保留原位置和内容；其他用户旧文件已移到归档/用户历史文件_20261016/。
