### ★ 实况调试台怎么用（`live_site_debug.py`）

```powershell
Set-Location "D:\university resource\大三上\视觉"
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\live_site_debug.py"
```

窗口里：**实时画面** + 零件掩膜（绿）+ 活动轮廓（红）+ HUD。
按键（**调完立刻能看到画面怎么变**）：

| 键 | 作用 |
|---|---|
| `q` / `ESC` | 退出 |
| `s` | 存一张原图 + 一张叠加图到 `工位帧/` |
| **`w`** | ★★ **把当前控件值写回 `config/camera.yaml`**（只替换 `controls:` 那一段，**注释全部保留**；先备份 `.bak`，并逐项打印旧值→新值） |
| `r` | 恢复成配置文件里的值 |
| `空格` | 暂停 / 继续 |
| `a` / `c` / `g` / `h` / `d` | 掩膜叠加 / 活动轮廓 / **金属掩膜** / **手套掩膜** / HUD 开关 |
| **`f`** | ★ **精细调节** 开/关（步长 ×0.2）—— 找到大致位置后微调用 |
| `[` `]` | 曝光 ∓10（自动关 AE） |
| `-` `=` | 增益 ∓4 |
| `,` `.` | 白平衡 ∓200K（自动关 AWB） |
| `;` `'` | 亮度 ∓5 |
| `9` `0` | 对比度 ∓5 |
| `o` `p` | 伽马 ∓20 |
| `k` `l` | 饱和度 ∓5 |
| `n` `m` | 锐度 ∓10 |
| `b` | AWB 自动 / 手动 切换 |

★ **掩膜、轮廓、调参三件事都在这一个窗口里**，不用换脚本：
`a` 管掩膜、`c` 管轮廓、`;` `'` / `9` `0` / `o` `p` / `k` `l` / `n` `m` 管亮度/对比度/伽马/饱和度/锐度。

★★ **`w` 写盘是"外科手术式"的**：只把 `realsense.controls:` 那几行换掉，
**其余每一行（含所有 ★ 依据注释）原样保留** ——
不能用 `yaml.safe_load` + `safe_dump`，那会把注释全清空（第一版就踩了这个，
已实测修正：★ 数量 81 → 81 不变）。写前会备份 `camera.yaml.bak`。

★ 看着画面把零件调到"掩膜整块盖住 + 连通域 = 4 个"，按 `w` 就固化了。
★ 离线试（不需要相机）：`--source images --path ..\assembly_vision\data\synthetic_seq --no-controls`

**★ `--parts-mask`：零件轮廓口径（`live_site_debug.py` 默认 `union`）**

用户实测报过「顶盖/立柱没轮廓、底座不是圆」—— 根因是**镜面高光把同一个零件切成碎片**：
底座那里 `brass` 只抓到**亮顶面**、`metal` 只抓到**暗边+阴影**，两块几乎不重合
⇒ 只看 `brass` 是**月牙**（圆度 0.26），`union` 才是**实心圆**（圆度 0.88）。

| 值 | 含义 |
|---|---|
| `union`（`live_site_debug.py` 默认） | `brass ∪ metal`，形状完整，**便于肉眼看** |
| `brass`（`capture_site_frame.py` 默认） | 与工程主链路一致，**定格留档 / 对账**用 |

★ 实测换口径**不引入新假阳性**：union 比 brass 多出的像素 **99.7% 落在料盘区内**；
区外那块（顶部木桌）与 `brass` 抓到的是**同一块**，且本来就靠 `work_roi` 挡。
详见 `工位帧/工位实测记录.md` §5.6。

★ 还能现场试阈值（**不写配置**）：`--s-min 25`、`--h-min 5`

★ **已把解释器钉在 `D:\miniconda\envs\yolov11\python.exe`**（OpenCV 5.0.0 + pyrealsense2 2.59.1）；
★ 已设 `console: integratedTerminal` —— **必须**，否则 OpenCV 的显示窗口与真实时间计时会不正常；
★ 已设 `PYTHONIOENCODING=utf-8` —— 否则 GBK 控制台打不出 `✓`/`²` 会"假崩"（实录 §2.41）。

### 前提：必须是**不受限**的进程

DSH 沙箱（受限 / 低完整性）里 **打不开 RealSense** ——
会报 `Mutex_TotalFailure` 或 `No device connected`，而**普通终端同一命令正常**
（实录 **§2.39**）。所以相机相关的 ①②④⑤⑥ 请在**你自己的 VSCode**里跑。

## 2. 命令行等价写法（工作目录在哪都行）

三个脚本的路径都由脚本自己算（`os.path.dirname(__file__)`），
所以**从工作区根、从 `assembly_vision`、从 `ai_测试工具` 里跑都一样**。

```powershell
# 内参 + 当前相机控件（固化控件、给 c3 做交叉检验用）
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\d435_intrinsics_check.py" --distance-mm 440

# 抓一帧存档（打印实际帧尺寸 + 色域 + 当前分割结果）
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\capture_site_frame.py" --tag after_lock

# ★ 白平衡/曝光扫描（锁了 AWB 之后色域会变，需要重新找值）
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\sweep_camera_controls.py" --auto-wb --tag wb1
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\sweep_camera_controls.py" --wb 4000,4600,5200,5800,6400,7000

# 分割色域对账（不带参数 → 先量 工位帧\原图\，再量换机期样张与旧机对照）
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\seg_gamut_report.py"

# 想留档：直接重定向
& D:\miniconda\envs\yolov11\python.exe "ai_测试工具\seg_gamut_report.py" > "ai_测试工具\工位帧\色域对账.txt"
```

`--distance-mm` ★ **已实测：440mm ±3mm**（料盘 160mm ±1mm）⇒ GSD **0.7287 mm/px**
（`fx=603.82` 反算；±3mm 只带 ±0.7% 误差）。

## 3. 目录里有什么

| 文件 | 是什么 | 谁在用 |
|---|---|---|
| **`capture_site_frame.py`** | ★ 抓一帧相机真实输出 → 打印帧尺寸/内参/色域/分割结果 → 存原图 + 掩膜叠加图 | 本轮新增，**"哪一帧算数"的仲裁工具** |
| **`d435_intrinsics_check.py`** | ★ 出厂内参（fx/fy/ppx/ppy + 畸变模型/系数）+ 逐模式 GSD 与覆盖 + **当前所有相机控件值** | 本轮新增；证明"内参不用标"+ 固化控件 |
| **`seg_gamut_report.py`** | ★ 黄铜/绿幕/手套色域 + `metal` 掩膜余量（打印"绿垫上界 ±5 邻域里有多少像素"） | 本轮新增 |
| `d435_site_report.py` | 换机对账单（曝光 / 色域 / 尺寸）—— 本轮从 `用户存档/` 移来的 AI 脚本 | 换机期 |
| `d435_seg_check.py` | 实时分割验证窗口 + `--analyze` 离线叠加图 | 换机期 |
| `d435_depth_fps.py` | 深度/红外/彩色+深度同时的帧率上限 | 换机期（换 D435 可行性论证） |
| `d435_fps_ceiling.py` | 彩色帧率上限（阻塞+回调双测法，证明 60fps 可开） | 换机期 |
| `d435_busy_probe.py` | `Device or resource busy` 排查 + 硬件复位 | 换机期 |
| `d435_frame_matrix.py` | 「开流但 0 帧」模式矩阵排查 | 换机期 |
| `工位帧/原图/` | 工位实拍帧、相机预览对照、Windows 设置截图 | ★ **证据，留存** |
| `工位帧/分析叠加图/` | 掩膜叠加图、料盘放大图 | ★ **证据，留存** |
| `工位帧/工位实测记录.md` | ★★ **所有实测数字 + 判据 + 复现命令** | ★ **数字的唯一落点** |

结论与数字全部写进 `工位帧/工位实测记录.md`，
**不留半成品代码，但量出来的图和数字全部留存**。
