## 快速离线检查

在仓库根目录的PowerShell中运行：

```powershell
$py = 'D:\miniconda\envs\yolov11\python.exe'
& $py 'assembly_vision/tests/run_all.py'
```

16个测试模块应全部通过。合成测试通过不代表真实工位验收通过。

## 目录与资料

- `assembly_vision/`：运行代码、阶段1数据工具、标定工具及回归测试。
- `ai_测试工具/`：保留的现场诊断工具；`阶段1数据/`保存本机原图、标注和实验产物，不入Git。
- `标注协作/`：队友共享素材与标注副本，合并后不得作为第二批数据重复计数。
- `用户存档/predict.py`：用户自己的测试文件，保留原位置和内容。
- `归档/用户历史文件_20261016/`：从用户文件夹移出的旧探针和图片，不是当前工具入口。
- `方案总纲_v3_4类零件.docx`：四类工件的原始方案参考；当前进度和执行顺序以有效任务卡为准。

过时任务卡、被替代方案和一次性诊断脚本已清理；需要追溯时查看Git历史。清理范围见[项目清理记录](docs/项目清理记录_2026-10-16.md)。
