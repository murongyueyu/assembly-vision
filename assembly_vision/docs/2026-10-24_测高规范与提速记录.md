## 1. 现场怎么用（5 分钟上手）

### 1.1 启动 / 退出

```bash
cd ~/assembly_vision
./deploy/pi/run_abcde.sh        # 960×540 窗口，性能候选 + 11 fps 配置
```

- 退出：窗口里按 `q`
- 复位（清空 4/4 与测量）：按 `r`
- 只有桌面会话下才能开窗口；SSH 里跑需要
  `DISPLAY=:0 XAUTHORITY=/home/pi/.Xauthority`

### 1.2 走一遍 4/4

1. 四个零件放进料盘对应槽（底座/立柱/轮盘/顶盖），停手 1～2 秒，等右上角
   `开工：等待D稳定放行` 变成 `已通过D并开工`；
2. 按 `底座 → 立柱 → 轮盘 → 顶盖` 顺序取走并装上去，每件要离开原槽 ≥8 px；
3. 进度到 `4/4`。

### 1.3 测高（B）

4/4 后在主窗口按 `i`：

1. 弹出 `Reference: bare green mat only` 窗口 → **框工件旁边 3～5 cm 的裸绿垫**，按 **Enter**；
2. 弹出 `Target: current assembly CAP top only` 窗口 → **框顶盖中心圆盘平面**，按 **Enter**；
3. 右侧面板出现 `快照测量：有效 xx.xxxx mm` + `高度符合性：合格/不合格` + `测量帧：xxxxx`。

按 `C` 或 `Esc` 取消选区；重测就再按一次 `i`。

## 2. B 测高规范（本次最重要的结论）

### 2.1 规则（以后一律照做）

| 项 | 要求 |
|---|---|
| 参考区 | 工件旁边 **3～5 cm** 的裸绿垫，**60×60 px** |
| 参考区禁区 | 黑料盘、零件、辐条、阴影、绿垫拼接缝、画面另一头的绿垫 |
| 顶盖区 | 装配体**中心圆盘平面**，**12×12 px** |
| 顶盖区禁区 | 螺丝槽、轮毂翻边、辐条、绿垫 |
| 其它 | 两框不能重叠；工件每次放回同一位置；记录**测量帧号** |

### 2.2 为什么：参考区远近的实测对比

同一件装好的装配体、同一套程序、同一块绿垫，只改参考区位置：

| 参考区 | 测量帧 | 读数 (mm) | 判定（67.000～73.000） |
|---|---|---|---|
| 画面最左，离工件约 30 cm | 40828 | 71.9801 | 不合格（高 0.70） |
| 同上 | 8244 | 73.6958 | 不合格（高 0.70） |
| 同上 | 14411 | 73.4808 | 不合格（高 0.48） |
| 同上 | 19644 | 59.6297 | 不合格（低 7.37） |
| 同上 | 49306 | 75.2888 | 不合格（高 2.29） |
| **工件右侧约 5 cm** | **53024** | **69.0355** | **合格** |

**原因**：B 先用参考区拟合一个平面，再把平面外推到顶盖处取高度。参考区离工件
30 cm 时，平面斜率的小误差被外推放大（经验：1° 斜率误差 ≈ 5 mm 高度误差），
工件一挪、视角一变读数就漂 ±15 mm；参考区贴着工件时外推距离趋近 0，读数回到
与物理量级一致（69 mm，与“装好约 70 mm”相符）。

### 2.3 判定窗口与基线

- 用户 2026-10-24 指定：装好的顶盖中心圆盘约 **70 mm**；
- 窗口：**67.000～73.000 mm**（70 ± 3），`upper_limit_mm: 73.0`；
- 2026-10-22 的“大于 68.5 mm 不合格”**作废**；
- 冻结的 B 源文件 `ai_测试工具/B模块深度/20261018_full_baseline_03/camera.native-depth.json`
  及其 hash **未改动**（原基线 68.025114 mm 仍可追溯）；
- 候选用 `height_assessment.baseline_mm: 70.0` 覆盖判定基线，实现在
  `assemvision/integration.py` 的 `Integration.__init__`（只对本候选生效）。

## 3. 检测帧率的四步提升

同一场景、同一配置、D435 640×480@30：

| 阶段 | 改动 | 无界面 | 带界面 | 单帧 |
|---|---|---|---|---|
| 起点 | 28 位姿（4 朝向×±3°）、A/C 串行 | 2.50 fps | 2.22 fps | 449 ms |
| ① | C 细搜 ±3° → ±1°（12 位姿） | 3.65 | 3.28 | 303 ms |
| ② | A 身份 ∥ C 观测（两线程） | 3.95 | 3.45 | 289 ms |
| ③ | 预分割线程（下一帧分割与当前帧 A/C 重叠） | 7.70 | 6.42 | 155 ms |
| ④ | C 只做 4 朝向（去掉 ±1° 微调，4 位姿） | **11.06** | **9.65** | **104 ms** |

视频侧始终 29.4～30.0 fps；带界面 CPU 约 272%，温度 72～73 ℃。

### 3.1 每步原理

- **①** C 每帧对角 4 朝向 × 7 个 ±3° 微调做整盘归一化相关，每次约 8 ms；
  收窄到 ±1° 后每帧 12 个假设，C 观测 222 ms → 107 ms。
  16 帧真实原图对比：方向角 **逐帧差 0.000°**、槽位状态一致。
- **②** A 身份（含 v5 分割）与 C 观测互不依赖，改常驻两线程并行；
  判据、阈值、输出不变。
- **③** C 分割（约 60 ms）原本串行在 A/C 之前。新增 `D-prep` 线程，在上一帧
  A/C 计算的同一时间预分割下一帧；**每帧只分割真正会被处理的那一帧**，不增加
  工作量。单帧 172 ms → 130 ms。
- **④** C 只做 4 个朝向（不再做 ±1° 微调），C 观测 107 ms → 39 ms；因为 ③
  之后 A 与 C 已经打平，这一步同时把核让给 A，整帧 130 ms → 90 ms。

### 3.2 代价与现在的瓶颈

- ④ 的方向角相对 28 位姿**稳定偏 −1.000°**（16 帧逐帧一致）；同一批帧的槽位
  空/有件状态、`observed_current` 完全一致。偏 1° 会让槽位多边形绕盘心转约 1°，
  正常件不受影响；**换新工位/新盘或贴边件必须复验**。
- ④ 之后 **A 身份成为下限**（约 85～107 ms，含 v5 分割）：
  再提速必须动 A 的分割/特征/确认节奏，会改变判据时序，需要单独候选与验收。
- 满载温度 73 ℃（空闲 45 ℃），Pi4 软降频线 80 ℃，长时间跑要留意散热。

## 7. 边界声明与待办

**边界**

- 所有结论来自**同一工位、同一场景、同一台 D435（SN 262322070302）**；
- B 仍是**单帧人工关联**测量，不是持续测高，不代表整机质量；
- 紧固性由队友负责；安装/辐条等其他质量项未验证；
- E 的 4/4 只代表取件顺序推定，不代表装配完成或合格；
- ④ 的 −1° 方向偏差只在当前 16 帧上核对过，未做多位置/多角度复验。

**待办（需要单独授权）**

1. 多场景/多角度复验 4 位姿的 −1° 偏差影响（尤其贴边件）；
2. 若要继续提帧率：动 A 的 v5 分割/特征复用（会改变身份确认节奏）；
3. 把 B 的参考面改为工件旁的固定小工装（贴纸/标记面），彻底消除人工取参考区的抖动；
4. 补一条 `tests/` 用例覆盖 `baseline_mm` 覆盖逻辑（当前只做了现场验证）。
