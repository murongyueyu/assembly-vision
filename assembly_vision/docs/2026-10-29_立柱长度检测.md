# 2026-10-29 立柱检测改为「横放量长度」

## 一句话

2/4 阶段的立柱检测从「深度法向高度 64 mm」改成**「横放后量轮廓长度 64 mm（杆长 + 底座）」**：
不再依赖深度（立柱高反光，D435 打不出点），改用同帧黄铜掩膜的轴向跨度。
比例用卡尺现场标定：**整体实测 63.42 mm vs 卡尺 64.0 mm（差 0.6 mm）**。

---

## 1. 为什么改

- 2026-10-28 量的是「立柱顶端到台面的高度」，但实测 D435 在立柱上**一个有效深度点都没有**
  （40×20 px 区域有效点 = 0，周围满格；全图最大高度 18.9 mm），B 的高度法根本测不了；
- 2026-10-29 用户改口径：**把装配好的立柱横放，量长度约 64 mm（含底座）**。
  长度只在图像平面内，用 mm/px 量轮廓即可，不受杆身高反光影响。

## 2. 口径与标定（关键）

| 量什么 | 像素 | 卡尺 | 反推 mm/px |
|---|---|---|---|
| **整体（杆 + 底座）** | 100.3 px | **64.0 mm** | **0.638** |
| 只算杆身 | 88.1 px | 58.0 mm | 0.658 |

⇒ 两个口径反推都落在 **0.65 附近**，而 `TrayMap.mm_per_px()` 给的是 **0.731**
（偏大约 12%，标定 homography 已过期）——所以长度阶段**必须用现场标定值**：

```yaml
    mm_per_px: 0.638      # 64.0 mm / 100.3 px，卡尺标定
```

判定用**整体口径**（杆长 + 底座），与用户口径一致；同一姿态复测可复现
（实测 63.42 mm，差 0.6 mm）。

> 待办：0.731 与 0.65 的 12% 差异说明 `calibration.yaml` 的 homography 与当前机位不符，
> 应当重跑 `calib/c3_tray_homography.py`；在那之前，凡是要**物理毫米**的判定都必须现场标定。
> 高度法（4/4 顶盖）用的是深度绝对毫米，不受这个比例影响。

| 文件 | 改动 |

| `assemvision/integration.py` | 阶段新增 `mode: height|length` 与 `mm_per_px`；新增 `measure_length()`；文案按模式显示「高度/长度」，面板加「长度比例」来源 |

| `config/abcde_integration_pi_column_candidate.yaml` | 立柱 `mode: length` + `mm_per_px: 0.638`，基线 64 / 容差 3；顶盖不变 |

| `tools/pi_diagnostics/length_probe.py` | 一次性工具：不跑 ABCDE，直接开相机量横放件长度 |

## 4. 操作约定（重要）

1. 四件归位，取 **底座 → 立柱**，拧好后**横放**到台面上，**手离开画面**；
2. 到 `2/4` 按 `i`，只弹**一个**测区窗口：
   `Target: current assembly COLUMN length | frame N | ENTER confirm / C cancel`；
3. **框住整体（杆 + 底座）**——这与"64 mm = 杆长 + 底座"的口径一致；
   只框杆身会读到 ~56 mm（杆身 58），会被判不合格；
4. 面板出 `轮廓：长 xx.xx mm / 宽 xx.xx mm / 角度 xx°`、`立柱长度符合性：合格/不合格`
   （窗口 61.000～67.000）以及 `长度比例：0.6380 mm/px（现场标定）`；
5. 4/4 顶盖仍是深度法，但**窗口同日改为 68.5 ± 1 = 67.500～69.500**（user 2026-10-29 授权，
   取代 10-25 的 65 ± 3 / 上限 68）。实测两次 68.33 / 68.03 mm，按新窗口均合格。

> ★ 手/手臂必须在测区外：皮肤也会过黄铜阈值，2026-10-29 实测把「零件+手」量成 150 mm。
> 蓝色手套不受影响（色相分离）。
