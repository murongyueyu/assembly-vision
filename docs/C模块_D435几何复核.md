跨文件的checks.py几何输入接线、test_size_gate.py面积口径两处已事先向用户说明并取得明确授权；原因和范围见[接线记录](C模块_跨文件最小接线提案.md)。不改D合格判据，不改A/B算法。65文件开工清单复核无越界变化；解析前后配置后排除C几何字段，其他值完全一致，详见freeze_verification_final.json。
