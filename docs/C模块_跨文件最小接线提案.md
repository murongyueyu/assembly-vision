# C几何最小跨文件接线记录（已获授权并实施）

按AGENTS.md §0.2.4，下面两个文件分别位于D判据与A测试范围，准备具体提案后询问用户。用户明确回复「允许这两个最小配套改动，提交中说明原因」，已按下述范围实施并通过18模块。下文保留提案时的原因与范围；不调整A/B算法，也不扩展为其他模块任务。

## 1. checks.py仅传递C几何输入

`_nominal_tray_px()`现用四角像素平均当盘中心；非仿射单应下它不是盘面中心的投影。拟改为按tray.size得到盘面中心再投影。`_pose_from_outline()`调用C的pose_from_tray_detect时增加`pixel_to_mm=lambda points: self.tray.px_to_mm(points, scale)`。

C函数已支持这个可选输入并通过独立投影测试；不传则保留局部GSD近似。实际右移参考图中，近似入口的投影中心与检测中心相差8.62px，不能把近似当全视野精确定位。这里仅让既有D调用使用C的标定映射，不改变合格性、覆盖率、身份、深度或装配判据。

**装配ROI随盘变换的问题不在本提案内**：仍作为独立移动尚未贯通的明确缺口，不借本次授权扩展改造。

## 2. test_size_gate.py只修测试面积口径

新槽位几何下，测试实际画入的木桌为565880px²，尺寸闸门报告恰好删除565880px²；旧断言却拿分割后补全连通域634002px²当分母，导致0.9比例断言失败。

已把`dropped_px >= 0.9 * blob_off.area_px`改为`dropped_px >= 0.9 * got_area`，提示文字及打印分母同步。got_area由测试直接数出实际画入的木桌像素。其余判据不变，不降低0.9阈值，不改A算法源码或分割阈值。先在内存验证，再于用户授权后修改正式测试，最终18模块通过。
