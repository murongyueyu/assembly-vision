# 阶段1首次完整离线开发比较（2026-10-16）

## 范围与结论

用户已离开工位，今晚只用现有原图离线测试。本轮仍是A模块，使用dev_01及dev_cap_smooth_01共64张开发图：54件正样本、8张空图、2张仅手套图；54份人工掩膜均已合并。

本轮比较旧模板基线与3种分割方案×3组特征，保留原始预测、失败样例和计时。没有连接相机、修改正式camera/workpiece配置、使用旧单应或启动神经网络训练。

**结论：传统视觉已有明确改进，值得继续；阶段1仍未验收。** 两个「种子补全＋近似尺度」候选在这批开发图上达到54件全部正确、负样本身份误报0/10，但模板也是从同批图拟合，不能证明新场景泛化。完整掩膜IoU中位数仅约0.753，低于0.85目标，仍需改善细结构分割。

## 1. 先查失败原因

- 原正式brass面积门槛为500px²。全部12根立柱在未按面积过滤时均可匹配到轮廓，面积范围411.5～565px²；500门槛下仅4个样本足以进入当前定位匹配。
- 18张顶盖对应轮廓面积390～561.5px²，500门槛会滤掉多数小件。
- 正式参数下，3种候选均因立柱可匹配样本4张小于模板最低8张而停止拟合；没有降低拟合样本数来绕过问题。
- 底座第9/10张存在强反光导致的色域分割破碎，不能只降低面积门槛就解决。

基于以上真实轮廓测量，另存实验policy，将面积门槛改为300px²比较。该值只是本批开发实验值，未写回正式workpiece.yaml。实验覆盖仅在内存副本上生效，禁止覆盖相机参数；模板和报告记录policy及正式配置hash。

## 3. 当前候选仍有何不足

seeded_metal_close / shape_scale在本批底座12/12、立柱12/12、轮盘12/12、顶盖18/18正确，身份FP均为0。
但按类别的掩膜IoU中位数为底座0.958、立柱0.729、轮盘0.737、顶盖外轮廓0.895；立柱与轮盘仍低于0.85。单张最差底座0.795、顶盖外轮廓0.779，也要保留作失败样例。
候选名称不表示已选定最终方案；种子补全与闭运算补全目前识别统计相同，仍需按分割误差分析差别。

本批覆盖仅为固定工位下的单件完整平放、有限反光与10张无零件图。没有独立批次验收，也没有完整验证取放/遮挡视频、明显阴影、相机重启、工位重摆及实际Pi4B性能。开发图54/54不是总体100%准确率。

## 4. 今晚与回工位后的安排

今晚可继续离线：

1. 对照立柱/轮盘的人工掩膜，量化漏掉的金属和多圈入的背景，分清色域、形态学及边界误差。
2. 依据这些失败再少量调整独立实验policy，记录改动、每类指标、全部失败图；保留本轮基线，不重复盲调。
3. 保留2个尺度候选作后续复核；若需要更多内部稳健性检查，可在开发素材内部验证，但不能代替独立工位批次。

回工位后再做：方法固定后重新摆放采独立验收图，录手套/拿取/遮挡序列，检查重启与现场光照变化；部署性能留后续G模块。
若传统视觉后续持续有针对性迭代仍无实质进展，再按已记录的技术路线启动YOLO等对照验证。目前已经观察到实质改进，还没有证据需要立即切换。
