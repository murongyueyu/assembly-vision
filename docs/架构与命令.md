**分层铁律**：`sources/` 只管图像从哪来；`core/` 只吃 numpy 与数据类，**不碰相机、不碰界面**；
`ui/` 只吃 `UIState`，不碰算法。改代码时不要打破这条线 —— 离线测试能跑全靠它。

## 2. 常用命令

```bash
cd assembly_vision

# ── 离线（不需要相机）────────────────────────────
python tools/make_synthetic.py --out data/synthetic --seq data/synthetic_seq \
        --calib config/calibration.synthetic.yaml
python tests/run_all.py                       # 12 个模块，应全绿
                                              # ★ 默认 GBK 控制台也全绿（run_all 已兜住编码，见 2.41）
python app.py --source images --path data/synthetic_seq \
        --calibration config/calibration.synthetic.yaml --no-ui --max-frames 200
python tools/ui_preview.py --renderer qt --out data/ui_preview

# ── 真机（必须用 yolo 环境的 python，见本节末）────────
PY='D:\miniconda\envs\yolov11\python.exe'
python tools/probe_d435.py                    # ★★ D435 先跑这个：设备/帧率/GSD/过曝 一次看全
python tools/probe_d435.py --reset            # 打不开/busy 时硬件复位（复位≠刷固件）
python tools/probe_camera.py                  # 旧 UVC 相机（HBV）专用；遇到 D435 会拦下
python tools/tune_slots.py                    # ★ 实时调覆盖率（摆零件时用）
python tools/measure_tray.py                  # 空料盘拍网格图，测槽位几何
python tools/record.py --seconds 60 --out data/videos/real1.mp4
python calib/c1_measure_fov.py --distance-mm 360      # ★ 已跑完：GSD 0.868
python calib/c2_stereo.py --cols 9 --rows 6 --square 19   # ★ 已跑完：B=126mm
python calib/c3_tray_homography.py --manual   # ★ 已跑完（自动识别角点，顺序无关）
python calib/c4_slot_baseline.py --frames 20  # ★ 已跑完：四槽各 20/20
python calib/c5_assembly_baseline.py --frames 20   # ★ 已跑完：辐条众数 8
python calib/c6_part_features.py              # ★ 已跑完：4 类零件模板
python tools/preview.py --guide assembly      # ★ 统一预览（ROI+分割+过曝报警）
python tools/part_track_demo.py                  # ★★ 零件检测实时演示（轮廓+追踪）
python tools/part_track_demo.py --bench                  # 只测帧率
python tools/part_track_demo.py --source images --path data/synthetic_seq --bench
python tools/part_track_occlusion_test.py        # 遮挡对照图（只描可见部分）
python tools/check_hand_box.py                   # 手（蓝手套）方框渲染验证
python tools/verify_glove_fix.py                 # 手套检出对账（有手要检出/无手要 0）
python tools/measure_glove_area.py               # 量手套面积分布（定 min_area_px 用）
python tools/measure_glove_gamut.py              # 量手套色域余量（定 h_min 用）
python tools/verify_allow_new.py                # 逐块看“新建轨迹”放行/拒绝及原因
python tools/verify_size_gate.py                # ★ 尺寸闸门离线对账（实录帧，不需相机）
python tools/fix_glove_fragments.py              # 扫闭运算核 x 面积闸门
python app.py --windowed                      # 正式跑（窗口模式方便调试）
```

**运行环境（★ 本机实测，别用错解释器）**：
- 必须用 **`D:\miniconda\envs\yolov11\python.exe`**（Python 3.11.9、**OpenCV 5.0.0**、numpy 2.2.6、PyYAML）。
  路径里有中文，命令里记得加引号。
- **不要用 `D:\miniconda\python.exe`（OpenCV 4.12）** —— 同一台相机在 4.12 下
  2560×960 只有 4.5 fps、1280×720 会掉帧，而 5.0 能稳在 31 fps。见 2.5。
- DSH 自带运行时**没有 cv2**，别用它跑相机相关的脚本。
- 快捷方式：`assembly_vision/run_calib.ps1 c1|c2|c3|live|eyes|app`（自动切目录 + 用对解释器）。

**OpenCV 5.0 与 4.x 的几处不兼容会直接崩**，详见 README 的 6.7 节：
`findChessboardCorners` 返回形状变了、`stereoRectify` 要求 `T` 是 `(3,1)` 且 `D` 是 `(1,N)`。
遇到 `cv::gemm` / `a_size.width == len` 断言失败，先怀疑**传给 OpenCV 的 numpy 数组形状**。
