## 2. 分层

- sources只负责取图；core只接收数组和数据类；ui只负责渲染；pipeline编排线程和流程。
- 阶段1工具独立处理原图，不用旧料盘槽位位置冒充身份真值。
- 不把离线候选参数直接写回正式配置；experiment.segmentation_overrides只对内存副本生效，并且仅允许segment.*。
- 主链路及旧标定仍保留供后续模块使用；旧HBV的几何/色域标定不等于D435已完成验收。

### 阶段1自动异常诊断（rev.3r.10）

从仓库根目录运行，四件在盘静置约10秒，随后底座移到绿幕/放回、蓝手套遮挡/移开，总计约30秒后q退出，无需按s：
