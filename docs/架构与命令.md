**分层铁律**：`sources/` 只管图像从哪来；`core/` 只吃 numpy 与数据类，**不碰相机、不碰界面**；
`ui/` 只吃 `UIState`，不碰算法。改代码时不要打破这条线 —— 离线测试能跑全靠它。

## 2. 常用命令

### ★★ 最快上手：在 VSCode 里按 F5

**用工作区根目录 `视觉\` 打开 VSCode**（不是 `assembly_vision\`），
按 `F5` → 选一条（**10 条已配好**，见 `.vscode/launch.json`）：

| 配置 | 干什么 | 要相机 |
|---|---|---|
| **★ 实况调试台** | **实时画面 + 掩膜/轮廓 + HUD + 键盘直调相机与分割阈值** ← 最常用 | ✅ |
| ① 抓工位帧 | 抓一帧定格：帧尺寸/内参/色域/分割结果 + 存原图与叠加图 | ✅ |
| ② 内参 + 相机控件 | 出厂内参 + 当前所有控件值 | ✅ |
| ③ 分割色域对账 | 黄铜/绿幕/手套 + `metal` 掩膜余量 | ❌ |
| ④ D435 逐模式帧率 | 帧率 / 过曝 / 存样张 | ✅ |
| ⑤ 实时预览 | 工程自带的 ROI + 覆盖率 + 识别 + 过曝报警 | ✅ |
| ⑥ 零件检测实时演示 | 形状轮廓 + 追踪 + 遮挡三档 | ✅ |
| ⑦ 离线回归 | 14 个测试模块 | ❌ |
| ⑧ 开流诊断 | 逐传感器列全部 profile + 逐个试开 | ✅ |
| ⑨ 白平衡/曝光扫描 | 扫一组值并排序给推荐 | ✅ |

★ 已钉好解释器 / `integratedTerminal`（**OpenCV 窗口必须**）/ `PYTHONIOENCODING=utf-8`（防 GBK 假崩）。
★ 相机相关的必须在**不受限**进程里跑（沙箱里报 `Mutex_TotalFailure`，实录 §2.39）。
★ **跑之前先关掉 Windows 设置里的相机预览页** —— 它会独占设备（实录 **2.43.1**）。

**运行环境（★ 本机实测，别用错解释器）**：
- 必须用 **`D:\miniconda\envs\yolov11\python.exe`**（Python 3.11.9、**OpenCV 5.0.0**、numpy 2.2.6、PyYAML）。
  路径里有中文，命令里记得加引号。
- **不要用 `D:\miniconda\python.exe`（OpenCV 4.12）** —— 同一台相机在 4.12 下
  2560×960 只有 4.5 fps、1280×720 会掉帧，而 5.0 能稳在 31 fps。见 2.5。
- DSH 自带运行时**没有 cv2**，别用它跑相机相关的脚本。
- 快捷方式：`assembly_vision/run_calib.ps1 c1|c2|c3|live|eyes|app`（自动切目录 + 用对解释器）。

**OpenCV 5.0 与 4.x 的几处不兼容会直接崩**，详见 README 的 6.7 节：
`findChessboardCorners` 返回形状变了、`stereoRectify` 要求 `T` 是 `(3,1)` 且 `D` 是 `(1,N)`。
遇到 `cv::gemm` / `a_size.width == len` 断言失败，先怀疑**传给 OpenCV 的 numpy 数组形状**。
