# D开工联检：组员演示

只展示「开工前四件是否各在正确槽位」，不启动组装工序或终检。

## 最省事：离线视频

双击 **Play-Video.cmd**，或直接打开同目录 **D-prestart-demo.mp4**。把这一个MP4发给组员即可播放，不需要Python、模型或相机。

视频约半分钟，依次展示：四件正确→缺轮盘→底座/顶盖互换且缺轮盘→手套遮挡轮盘→四件恢复。
零件有当前真实轮廓及身份标签；手只有矩形框；错放/缺件红色报警；遮挡等待、取消放行。
视频是本轮真实原图经交付程序的分场景离线回放，片段间重新初始化；不是连续一次真实操作，也不是新增验收样本。

## 现场演示

在本机当前工位接好D435 USB3，保持原相机位置/光照，戴蓝手套。双击 **Start-Live.cmd**。
模型/policy、正式calibration和相机配置依赖本机冻结数据；其他电脑仅克隆Git不能直接复原现场。给组员远程展示时可在本机共享窗口，或发送上述视频。

建议按顺序演示，每次操作后手退出、等待状态稳定：

1. 四件各在正确槽：四类身份与轮廓正确，显示「可以开始组装」。
2. 轮盘拿到画外：具体报警缺轮盘，其他槽保持匹配。
3. 底座与顶盖互换：两个槽分别显示应为谁、实为谁，禁止放行。
4. 四件恢复正确后，用蓝手套遮轮盘：只框手，轮盘不确定、取消放行，不误报缺件。
5. 手退出：重新稳定后恢复放行。

按 **Q / Esc** 结束。默认一直运行，退出后释放相机。

PowerShell也可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\D模块演示\Start-Demo.ps1'
```

## 讲解口径

「A先独立识别零件，C确定当前槽位，D检查身份和槽是否一一对应。绿色只表示当前四槽开工匹配；不代表紧固、高度或整机质量合格。」

未知物体、手遮挡、方向拒识、跨帧/过期/异常不会放行；未知不能强行当错件。已有可靠独立身份和明确槽归属的错放会具体报警，不能被覆盖率不确定带掩盖。
界面顶部继承的装配进度0/0无工序含义。本轮D收尾，不继续E。

交付证据与限制见[完整D记录](../docs/D模块_开工前匹配联检.md)。视频可由make_demo.py依赖本机现场原图重新生成，模型和原图不随Git分发。
